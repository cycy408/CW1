# CW1
主要就是一个python学习代码的小游戏，未来可能会加入unity进行美化
首先是登录界面，用户需要先注册再进行登录，一旦发现异常，都会要求用户进行重新登录。

第一部分是简单的知识问答，这一部分是一开始的设想，后来觉得有些单调并且不符合游戏的要求所以接着往后加了，这一部分简单的6个等级，简单的五个问题，达到40分即可通关，加入了进度保存，随时退出也可以自动保存，这里后续如果还想继续优化，希望可以增加选择关卡功能。

下一部分是滑块拖瑞，这一部分灵感来源于多邻国，同时claudecode大开智，增加了管家选择和显示的页面，还是挺好看的，但是整体风格不统一，什么原因我也没想明白。

最后一部分是这个宇宙飞船答题的形式，原计划是让他变得更趣味，但是太傻了，没有游戏策划的天赋，想半天没弄懂通关逻辑，所以做了一坨大的，但是基本动画还是做了一点。主要为了用上上课讲的pygame。（绝对不是我不会），这一部分答题的逻辑和第一部分相同，只是计分阶段加上了动态的计分逻辑，嗯，（比较容易完红温）。比如答错题加boss血量，连对可以扣boss更多血量，其实相加那个打不中就不得分，但是我测试玩红温了，通不了关，遂放弃。

这个小糊项目的逻辑基本就是这样。
